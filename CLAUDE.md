# Skull Shaft — заметки для Claude

Ритм-раннер по вертикальной шахте под трек владельца. Сначала был опубликован как артефакт на claude.ai (https://claude.ai/artifact/9eLPqaRvsoKg1xZEkZGZuN), теперь переезжает в Telegram Mini App.
Владелец проекта — не программист. Отвечать **по-русски**, простыми словами, без жаргона; команды и пути — в блоках кода. Компьютер владельца — Windows, папка проекта `C:\nazjrov\Production\ClaudeCode\Projects\1.SkullShaft`.

## Как работать с владельцем (обязательно)

1. **Сначала уточнять, потом делать.** На каждую новую задачу: как я понял (1–3 толкования) → варианты и подварианты исполнения → мой фаворит и почему → ждать «да». Не начинать без «да». Мелкие очевидные правки после явного «сделай» — можно сразу.
2. **Работать по частям.** Не переписывать файл целиком, править точечно (владелец бережёт лимиты).
3. **Визуальные изменения — сначала превью** (картинка/гифка из отдельной страницы, не в игре), встраивать после одобрения.
4. Если он говорит «стоп» / «пока ничего не меняй» — остановиться сразу.
5. В конце — коротко что сделано и что проверить ему.

## Стиль (одобрено владельцем)

- Современная, глубокая, чёткая графика: тёмный хром/металл + красный. **Не пиксель-арт. Без неона.**
- Без надписей на экране типа «ВОЛНА / ДРОП». Без резких поворотов камеры (в дропе — только мягкое покачивание). Без чёрного кадра перед дропом.
- Акценты на сильных долях: вспышка, смаз, искры, лёгкое дрожание.
- Фон: шахта (цепи, факелы, ниши с черепами, решётки, кровь, руны, крюки); в дропе — ад.
- **Череп-босс**: 3D-модель владельца из Blender (`assets/skull.glb`, узлы `Skull` и `Jaw`), хром, горящие красные глаза. Следит за героем поворотом головы, щёлкает челюстью. Укус на битах 16 и 32: рывок к экрану → смотрит влево → вправо → безумно смеётся → отъезжает. В режиме стен череп НЕ бегает за героем из стороны в сторону (одобрено: «это офигенно»).
- **Герой**: в волне — хромовый сюрикен с красным ядром. На стенах — «шлем на ногах», вариант A2 (`docs/refs/hero-walker-A2.png`): мотошлем с красной полосой и красными глазами за визором, две ноги на шарнирах по бокам, без рук. Цикл бега: шаг на полбита, подпрыгивание вниз на постановке ноги/вверх на толчке, кивок, лёгкое сплющивание (`docs/refs/hero-run-cycle.gif`). В прыжке через шахту — крутящийся шлем.
- Отклонено: SDF-череп, «2.5D»-череп из картинки, пиксельная графика, неон, мелкие полочки-платформы.

## Механика и уровень

- Трек 103.19 BPM, первая доля на 0.565 с (`BPM`, `PH` в `src/game.html`). Уровень кончается после первого дропа: бит 48 (~0:28).
- Секции (`SECTIONS`): 0–8 волна (держи — вправо, отпусти — влево), 8–16 зеркальная волна (управление наоборот), 16–48 стены (тап — перелёт на другую стену, иногда на центральный столб), 48 — финиш.
- Все повороты и прыжки стоят на тапах владельца (`TAPS0`, разметка по четвертям). Коридор волны — один зигзаг, поворачивает только на тапах. На стенах — ритмичные шипы на противоположной стене между тапами (наказывают ранний/поздний прыжок), окно попадания примерно −0.2…+0.15 бита.
- Анализ трека: бас дропа реально бьёт на бите 17 (10.45 с), а портал в стены стоит на 16. Владелец решил **пока оставить 16**.
- Бессмертие — кнопка разработчика в HUD.
- Звук: трек декодируется заранее (OfflineAudioContext), AudioContext создаётся внутри тапа «Играть» (для iPhone). Подтверждения от владельца, что звук на iPhone теперь работает, ещё нет.

### Карта как данные + редактор (`src/editor.js`)

`MAP = {taps, G:[ширина коридора волны, зеркала], entry: ±1 стартовая стена, posts:[тапы-столбы], noSpike:[тапы без шипов перед ними]}`. `defaultMap()` точно воспроизводит исходный уровень. `buildLevel()` строит уровень из `MAP`. Версия карты `mapVer()`: исходная = `lvl1v4`, иначе `m<hash>`; у каждой версии свои рекорды.
Редактор (сейчас виден только владельцу артефакта, или по `#edit` в адресе): таймлайн по битам с реальной геометрией, добавить/выделить/перетащить/удалить прыжок, столб, шипы вкл/выкл, ширина коридора, стартовая стена, сетка 1/4–1/8, масштаб, отмена, «Слушать» с добавлением прыжков в ритм (пробел), «Играть с бита» (без рекордов), код карты (экспорт/импорт), «Сохранить» в общую карту.

### Хранилище сейчас (claude.ai, `window.claude.use("db")`)

- Рекорды: коллекция `lvl1v4`, документ на игрока `{best, att, clearAtt, rank, ver, at}`; правило: читают все, пишет каждый только свой.
- Общая карта: документ `map/lvl1`, пишет только владелец.
- В Telegram этого хранилища нет — его надо заменить (см. план).

## Файлы

- `src/game.html` — игра (HTML+CSS+JS), с плейсхолдерами `/*DATA*/ /*TRACK*/ /*SKIMG*/ /*SKULLGL*/ /*EDITOR*/ /*SKGLB*/`.
- `src/editor.js` — редактор карты. `src/skullgl.js` — маленький WebGL-рендер GLB черепа (хром, глаза, шарнир челюсти). `src/beats.js` — анализ трека по восьмым (LOW/MID/ONS) для вспышек.
- `assets/` — `track.mp3` (в игре), `track-original.m4a`, `skull.glb`, `skull-fallback.png` (если нет WebGL).
- `tools/build.mjs` — собирает `dist/index.html` (один файл, всё внутри, ~2.9 МБ). `--test` → `test-out/bot.html` (автопилот) и `test-out/god.html`.
- `tools/bot-test.mjs` — бот проходит уровень (нужен playwright). Ожидается `won` при смещении 0.
- `docs/refs/` — одобренные рефы героя, скрины редактора и дропа, кадры 2016 года.

Сборка: `node tools/build.mjs`. Проверка: `npm i -D playwright && npx playwright install chromium && npm test`.

## План: переезд в Telegram (одобрен в общих чертах)

1. Git-репозиторий → GitHub, автодеплой на GitHub Pages (игра в `dist/`). Следить, чтобы Telegram не держал старую версию в кэше.
2. Supabase (бесплатный тариф): таблицы рекордов (по версии карты), общая карта, события забегов для статистики. Каждый запрос проверяет `initData` Telegram на сервере (Edge Function, HMAC с токеном бота). **Токен бота владелец вставляет сам в секреты Supabase — не просить его в чат и не коммитить.**
3. В игре — слой-адаптер: те же функции рекордов/карты, но через Supabase вместо `window.claude`. Желательно, чтобы игра продолжала работать и на claude.ai.
4. Telegram WebApp SDK: `ready`, `expand`/полный экран, отключить вертикальные свайпы, вибрация на прыжках, кнопка «назад». Имена и аватарки — из Telegram.
5. Редактор карты — только для Telegram-ID владельца; сохранение → у всех новая карта при следующем запуске.
6. Админ-панель (только владелец): игроки, забеги, где чаще умирают (по битам), рекорды по версиям, удаление нечестных рекордов.
7. Бот — владелец создаёт сам через @BotFather, подсказать шаги.
Игроки — из России, все под VPN.
