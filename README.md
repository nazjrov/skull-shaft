# Skull Shaft

Ритм-раннер по шахте под трек. Готовая игра одним файлом — `dist/index.html` (открывается в браузере двойным кликом).

Как начать работу в Claude Code:
1. Приложение Claude → вкладка **Code** → **Local** → **Select folder** → эта папка.
2. Первое сообщение: «Прочитай CLAUDE.md и скажи, что понял про проект».

Всё о проекте, решениях и плане переезда в Telegram — в `CLAUDE.md`.
